# Kayriva 1.0 Beta 2 — A smoother workspace

Beta 2 refines everyday conversations, attachments and long-running task controls.

## Improvements

- Open attached images in a larger preview with fit and zoom controls.
- Follow work through concise progress updates and expandable operation groups.
- Resume controls now appear only on the latest interrupted response, and disappear after the conversation moves on.
- Browse every catalog variant in a compact model list, with optional family grouping and collapsible filters.
- See and switch the project directly above the composer; new conversations retain the selected project.
- Refined control spacing, compact layouts and English/Turkish interface text.
- More responsive connection cancellation and bounded waits for unavailable services.
- Small pasted images retain their resolution instead of being enlarged during preparation.

## Install

**Windows x64:** Run `Kayriva-Setup.exe`.

**Linux x64:** Download `Kayriva-x86_64.AppImage`, enable its executable permission and launch it:

```bash
chmod +x Kayriva-x86_64.AppImage
./Kayriva-x86_64.AppImage
```

The optional `Kayriva-1.0.0-beta.2-linux-x86_64.tar.gz` preserves executable permission and includes the same AppImage and a short guide. This Linux build requires **glibc 2.43 or newer**. If FUSE mounting is unavailable, use `--appimage-extract-and-run`.

Model weights and runtime packages are separate downloads. Existing user data is stored separately from the installed application.

Model speed and document quality depend on the selected model, runtime and hardware. Important generated claims should be checked against their sources.
