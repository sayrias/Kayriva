# Kayriva 1.0 Beta 1 — Your own workspace, your local model

Kayriva's first public beta brings local model chat, project files, web research and MCP tools into one native desktop workspace.

Inference happens on your computer. Kayriva manages its own llama.cpp runtime, including installation and process lifecycle.

## Included in this beta

- **A broader model library:** 141 variants across 71 model families and 18 brands. NVIDIA contributes 32 variants; filters cover publisher, task, file size and memory class.
- **Projects and persistent conversations:** Project chats, search, pins, editable prompts and Markdown export.
- **File workflows:** Read, search, create and edit code/text files; extract text from PDF, DOCX, XLSX and PPTX attachments. Inspect images with a compatible model and matching projector.
- **Research and planning:** Three research modes, a source list, HTML/PDF reading, plan mode, operation stages and configurable task limits.
- **MCP and GitHub:** An extension library, editable assistant profiles, repository browsing/creation and reviewed uploads of selected project files.
- **Hardware-aware controls:** CPU, Vulkan and NVIDIA CUDA runtimes; GPU + RAM placement, memory budgets, a low-memory profile and model residency options.
- **Local usage monitoring:** Live/historical counters, charts, generation speed and local error logs.
- **A refined native interface:** Graphite/lavender surfaces, project and conversation navigation, compact controls and settings within the main window.
- **Language support:** English by default, with English/Turkish selection in General settings.
- **Updates from day one:** GitHub release checks in About, automatic verified staging, optional block-delta downloads and a restart chosen by the user.

## Install

**Windows x64:** Run `Kayriva-Setup.exe`.

**Linux x64:** Extract the `.tar.gz` archive if using it, then make `Kayriva` executable and launch it:

```bash
chmod +x Kayriva
./Kayriva
```

The current Linux build requires **glibc 2.43 or newer**. The archive contains the same executable and has the same system requirements. Measured requirements are included in `compatibility.json` in the archive.

Download or import a model under **Settings → Models**, then prepare a suitable runtime under **General → Local runtime**. Model weights and runtime packages are separate from the installer. Linux builds need compatible system libraries.

## Beta scope

Model support, speed and memory needs vary by architecture, runtime version and hardware. Not every catalog model has been tested on a physical GPU. Vision requires a matching `mmproj`. Optional Transformers dependencies are not part of the standard distribution.

Inference is local. Web research, downloads, GitHub and enabled MCP connections contact their respective external services. There is no application telemetry.

When reporting a problem, include your operating system, Kayriva version, model/runtime names and reproduction steps. Review logs and screenshots for personal information before sharing them.
